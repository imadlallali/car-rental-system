# car-rental-system
Car rental system where I implemented CRUD operations to simulate the common functions such as adding, removing, renting, returning, displaying cars etc..

Implemented object-oriented programming practices such as inheritance and abstraction to create different types of cars (Economy/VIP), aggregation and composition.
